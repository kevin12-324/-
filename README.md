# 🧛 뱀서류: 생존게임

Unity로 만든 뱀파이어 서바이벌 스타일 게임입니다.

## 📖 게임 개요

플레이어가 계속 나타나는 적들로부터 생존하면서 경험치를 모아 강해지는 게임입니다.
시간이 지날수록 난이도가 올라가고, 다양한 스킬을 선택하며 게임을 진행합니다.

## 🎮 주요 기능

- **자동 공격 시스템**: 플레이어 주변 적들에게 자동으로 공격
- **적 웨이브 시스템**: 시간이 지날수록 더 많은 적이 나타남
- **경험치 & 레벨업**: 적을 처치하여 경험치 획득 후 스킬 선택
- **다양한 스킬**: 플레이어의 전투 스타일을 강화하는 스킬들
- **UI 시스템**: 체력, 점수, 경험치 바 표시
- **게임 오버**: 체력이 0이 되면 게임 종료

## 🛠️ 기술 스택

- **엔진**: Unity (2022 LTS 이상)
- **언어**: C#
- **버전 관리**: Git & GitHub

## 📁 프로젝트 구조

```
Assets/
├── Scripts/
│   ├── Player/          # 플레이어 관련 스크립트
│   ├── Enemy/           # 적 관련 스크립트
│   ├── Managers/        # 게임 매니저, 스폰 매니저 등
│   ├── UI/              # UI 관련 스크립트
│   └── Systems/         # 공격, 경험치 시스템
├── Prefabs/             # 플레이어, 적, 이펙트 프리팹
├── Scenes/              # 게임 씬
├── Sprites/             # 캐릭터, 이펙트 스프라이트
└── Audio/               # 배경음, 효과음
```

## 🚀 시작하기

### 1. 저장소 클론
```bash
git clone https://github.com/kevin12-324/-.git
cd -
```

### 2. Unity에서 프로젝트 열기
- Unity Hub에서 "프로젝트 추가" 클릭
- 프로젝트 폴더 선택
- Unity 2022 LTS 이상 버전으로 열기

### 3. 게임 실행
- Unity 에디터에서 Assets/Scenes/GameScene 씬 열기
- Play 버튼 클릭하여 게임 시작

## 🎯 게임 플레이

- **이동**: WASD 또는 화살표 키
- **공격**: 자동 (적에게 가까워지면 공격)
- **레벨업**: 경험치를 다 모으면 스킬 선택 화면이 나타남
- **목표**: 최대한 오래 생존하기!
