# 뱀서류: 생존게임 🧛

Unity로 만든 뱀파이어 서바이벌 스타일 게임입니다.

## 🎮 게임 개요

끝없이 나타나는 적들로부터 생존하세요! 적을 처치하여 경험치를 얻고 레벨을 올려 강력한 스킬을 획득하세요.

## ✨ 주요 기능

- 🧛 자동 공격 시스템
- 👹 다양한 적 스폰
- ⭐ 경험치/레벨업 시스템
- 🎯 스킬 선택 메커니즘
- 💾 게임 진행 상태 저장
- 🎵 사운드 & 이펙트

## 🛠️ 개발 환경

- **엔진**: Unity 2022 LTS 이상
- **언어**: C#
- **버전 관리**: Git/GitHub

## 📁 프로젝트 구조

```
Assets/
├── Scripts/          # C# 게임 스크립트
├── Scenes/           # 게임 씬
├── Sprites/          # 2D 그래픽 리소스
├── Prefabs/          # 재사용 가능한 게임 객체
├── Audio/            # 사운드 & 음악
└── UI/               # UI 프리팹 & 스프라이트
```

## 🚀 시작하기

1. Unity Hub에서 프로젝트 열기
2. Assets/Scenes/MainScene 씬 실행
3. Play 버튼으로 게임 플레이
